# ARC Associates - Modern Construction Web Platform

Official website and digital showcase platform for **ARC Associates** (Cuddalore, Tamil Nadu), established in 1998.

## 🏗️ Features
- **Modern Architectural UI**: Ultra-responsive layout with rich aesthetic design tokens, smooth animations, and luxury construction themes.
- **Dedicated Services Hub & Subpages**: Comprehensive breakdowns for Houses & Offices, Renovations, Electrical, Plumbing, Modular Carpentry, and Italian Marble Flooring.
- **3D Coverflow Projects Showcase**: Interactive 3D perspective carousel with category filtering.
- **Interactive Cost Estimator**: Live building cost calculator with area and tier adjustments.
- **Auto-Sliding Google Reviews Marquee**: 10 verified Google 5-star reviews with infinite loop and interactive pause/play controls.
- **Admin Photo Portal**: Client-side canvas-based automatic image compressor and tagger that resizes site photos and syncs live with the public portfolio.
- **Full SEO & Structured Data**: Meta tags, OpenGraph, and Schema.org JSON-LD for local business search optimization.

## 📁 Tech Stack
- HTML5 (Semantic structure & Schema.org)
- CSS3 (Custom properties, 3D transforms, glassmorphism, flex/grid)
- ES6+ JavaScript (SPA routing, canvas image optimization, local storage persistence)

## 🚀 Running Locally
Open `index.html` in any modern web browser or serve with:
```bash
npx serve .
```
